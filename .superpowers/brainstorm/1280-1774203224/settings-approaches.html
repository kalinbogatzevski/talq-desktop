C: Sidebar + Content Split

Settings nav on left, content on right — always visible together. Like VS Code or Discord. Most space-efficient for browsing, but adds a third column to TalQ's layout.

Recommendation: B (Telegram-style)

Fits TalQ's existing navigation pattern — you already have StackView for splash→login→chat transitions. Settings becomes another screen in that stack. Category list → detail view matches how Telegram does it. Simple to implement, room to grow, no extra columns.
