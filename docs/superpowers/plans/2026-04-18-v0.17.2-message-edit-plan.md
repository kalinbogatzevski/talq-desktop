# v0.17.2 Message Edit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users edit their own text messages in TalQ via a right-click "Edit" action and an inline editing bar, mirroring the existing reply-bar UX and the existing `deleteMessage` API pattern.

**Architecture:** New `MessageListModel::editMessage` hits `PUT /ocs/v2.php/apps/spreed/api/v1/chat/{token}/{messageId}`; the server echoes the updated message with `lastEditTimestamp`, which `Message::fromJson` stores and `ChatPainter` renders as a `(edited)` prefix on the time label. The composer grows an editing bar sibling to the existing reply bar and branches its send path to emit `editMessageRequested` when editing is active. MainWindow owns `m_editingMessageId` and wires the flow.

**Tech Stack:** Qt6.8.2 Widgets, MinGW 13.1, existing `ApiClient`, `MessageListModel`, `ComposerWidget`, `ChatPainter`.

**Spec:** `docs/superpowers/specs/2026-04-18-v0.17.2-message-edit-design.md`

void MessageListModel::editMessage(int messageId, const QString &newText)
{
    if (m_token.isEmpty() || messageId <= 0) return;

    // Find the message in our local store — bail if we don't know it.
    int idx = -1;
    for (int i = 0; i < m_messages.size(); ++i) {
        if (m_messages[i].id == messageId) { idx = i; break; }
    }
    if (idx < 0) {
        emit errorOccurred(QStringLiteral("Cannot edit: message not found locally"));
        return;
    }

    QJsonObject body;
    body["message"] = newText;
    QString path = "apps/spreed/api/v1/chat/" + m_token + "/" + QString::number(messageId);
    QString token = m_token;  // capture for stale-callback guard

    m_api->put(path, body,
        [this, messageId, token](bool ok, const QJsonObject &data, int status) {
            // Stale-callback guard — conversation may have switched mid-flight.
            if (m_token != token) return;
            if (!ok) {
                QString err = data.value("ocs").toObject()
                                  .value("meta").toObject()
                                  .value("message").toString();
                emit errorOccurred(err.isEmpty()
                    ? QStringLiteral("Failed to edit message (HTTP %1)").arg(status)
                    : QStringLiteral("Failed to edit: %1").arg(err));
                return;
            }
            // Server echoed the updated message — replace the local entry.
            QJsonObject updated = data.value("ocs").toObject()
                                      .value("data").toObject();
            for (int i = 0; i < m_messages.size(); ++i) {
                if (m_messages[i].id == messageId) {
                    m_messages[i] = Message::fromJson(updated);
                    QModelIndex mi = index(i);
                    emit dataChanged(mi, mi);
                    break;
                }
            }
        });
}
```

void ComposerWidget::showEditingBar(const QString &originalText)
{
    // Editing and replying are mutually exclusive.
    if (m_replyBar && m_replyBar->isVisible())
        hideReplyBar();

    QString preview = originalText;
    preview.replace(QLatin1Char('\n'), QLatin1Char(' '));
    if (preview.size() > 120) preview = preview.left(120) + QStringLiteral("…");
    m_editingPreview->setText(preview.toHtmlEscaped());
    m_editingBar->show();

    m_input->setPlainText(originalText);
    QTextCursor c = m_input->textCursor();
    c.movePosition(QTextCursor::End);
    m_input->setTextCursor(c);
    m_input->setFocus();
    m_editing = true;
}

void ComposerWidget::hideEditingBar()
{
    if (!m_editing && (!m_editingBar || !m_editingBar->isVisible())) return;
    m_editing = false;
    m_editingBar->hide();
    m_input->clear();
    emit editingBarCancelled();
}
```

void ComposerWidget::sendAction()
{
    // If a file is pending, Enter sends the file (with caption from composer)
    if (!m_pendingFilePath.isEmpty()) {
        confirmSendFile();
        return;
    }
    QString text = m_input->toPlainText().trimmed();
    if (text.isEmpty()) return;
    if (m_signaling) m_signaling->sendStoppedTyping();

    if (m_editing) {
        emit editMessageRequested(text);
        hideEditingBar();   // MainWindow will clear m_editingMessageId via editingBarCancelled

    m_input->clear();
}
