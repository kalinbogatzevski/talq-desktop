# v0.17.3 Unread Divider Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw a "New messages" pill across the chat above the first unread message when reopening a conversation, plus a faint teal tint over the unread region, matching the NC Talk web convention.

**Architecture:** `MessageListModel` snapshots `Conversation::lastReadMessage` into `m_unreadBoundary` before the existing `markAsRead()` call advances the server value. `ChatPainter` receives the boundary via signal, finds the first layout with `id > boundary` during `rebuildAllLayouts`, decorates it with `showUnreadSep` + a reserved strip, and paints the pill and tint during `paintEvent`. No layout-engine signature churn — the divider is post-hoc decoration on top of the existing layout code.

**Tech Stack:** Qt6.8.2 Widgets, existing `MessageListModel` / `ConversationListModel` / `ChatPainter` / `LayoutEngine` / `PainterTheme`.

**Spec:** `docs/superpowers/specs/2026-04-18-v0.17.3-unread-divider-design.md`

### Task 5: Mark the separator row in `rebuildAllLayouts`

**Files:**
- Modify: `src/painter/ChatPainter.cpp`

- [ ] **Step 1: Pre-compute the first-unread layout index**

At the top of `rebuildAllLayouts` (inside the function, after `preH` is captured and `m_layouts` is cleared, before the main `for (int i = 0; i < count; ++i)` loop), add:

```cpp
    // Find the first layout position (oldest-first) whose message.id exceeds
    // the unread boundary. If none, no separator is drawn.
    int firstUnreadLayoutIdx = -1;
    if (m_unreadBoundary > 0 || m_model->rowCount() > 0) {
        for (int i = 0; i < count; ++i) {
            int modelRow = count - 1 - i;
            int id = m_model->data(m_model->index(modelRow),
                                   MessageListModel::IdRole).toInt();
            if (id > m_unreadBoundary) { firstUnreadLayoutIdx = i; break; }
        }
    }
```

Note: if `m_unreadBoundary == 0` (never opened), every real message id is > 0, so `firstUnreadLayoutIdx` will be the first non-system message — matches the "all new" behavior from the spec.

Add near `paintDateSep` (grep `void ChatPainter::paintDateSep` to find it):

```cpp
void ChatPainter::paintUnreadSep(QPainter *p, const MessageLayout &ml, qreal offsetY)
{
    if (!ml.showUnreadSep || ml.unreadSepRect.isEmpty()) return;

    QRectF strip = ml.unreadSepRect.translated(0, offsetY);

    QFont pillFont = m_theme.dateSepFont();
    QFontMetrics fm(pillFont);
    QString text = tr("New messages");
    int textW = fm.horizontalAdvance(text);
    int pillW = textW + 20;

    qreal cy = strip.center().y();

    // Teal accent line across the full strip.
    p->setPen(QPen(m_theme.accent, 1));
    p->drawLine(QPointF(strip.left(), cy), QPointF(strip.right(), cy));

    // Centered pill with teal text over the conversation background.
    QRectF pill((strip.width() - pillW) / 2.0 + strip.left(),
                cy - PainterTheme::unreadPillHeight / 2.0,
                pillW, PainterTheme::unreadPillHeight);
    p->setPen(Qt::NoPen);
    p->setBrush(m_theme.bgChat);
    p->drawRoundedRect(pill, pill.height() / 2.0, pill.height() / 2.0);

    p->setPen(m_theme.accent);
    p->setFont(pillFont);
    p->drawText(pill, Qt::AlignCenter, text);
}
```

If `m_theme.bgChat` isn't the right field for the chat background (grep `PainterTheme` for bg-related members — could be `bgDefault`, `bgWindow`, `bgChat`), substitute the one actually used as the ChatPainter background. The goal is that the pill occludes the accent line behind it.
